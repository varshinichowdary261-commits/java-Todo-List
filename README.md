# My To-Do List

## Project Description

My To-Do List is a simple Java console-based application used to manage daily tasks.

The user can add tasks, set their priority, view tasks, mark tasks as completed, delete tasks, and search for a particular task.

## Features

* Add a new task
* Set task priority
* View all tasks
* Mark a task as completed
* Delete a task
* Search for a task
* Each task has a unique ID

## Technologies Used

* Java
* ArrayList
* Classes and Objects
* Methods
* Loops
* Conditional Statements
* Switch Statement
* Scanner

 How to Run

** Step 1

Install Java on your computer.

** Step 2

Open the project in VS Code or any Java IDE.

** Step 3

Compile the program:


javac TodoList.java

** Step 4

Run the program:


java TodoList
